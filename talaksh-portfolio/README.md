# Talaksh Portfolio

React + Vite personal portfolio.

## Run locally

```bash
npm install
npm run dev
```

## Customize

- Update `src/App.jsx` for your project links, descriptions, skills and education.
- Add your actual PDF resume at `public/resume.pdf` before publishing. The resume button points there.
- The GitHub profile is prefilled. Add a LinkedIn link if desired.
- Verify all experience, degree names, and technical claims before publishing.

## Build

```bash
npm run build
```

Deploy the `dist` output to a static host, or import this repository into Vercel or Netlify.
